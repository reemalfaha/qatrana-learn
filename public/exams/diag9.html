بيانات الطالبة

تعليمات: اختاري إجابة واحدة صحيحة لكل سؤال. لا علامة سالبة على الخطأ، فأجيبي عن الجميع. الزمن المقترح ٥٥ دقيقة. تأمّلي الرسم أو الجدول جيداً قبل قراءة الخيارات في أسئلة المحور الخامس. عند الانتهاء اضغطي «تصحيح الاختبار وحفظ النتيجة»؛ يظهر التصحيح وتقرير نقاط القوة والضعف وخطتكِ العلاجية، وتُحفظ النتيجة وتُرسل إلى جدول المعلمة في اللحظة ذاتها.
الغاية: اختبار تشخيصي لا يُحتسب ضمن العلامة المدرسية، هدفه تحديد نقطة الانطلاق وبناء خطة تعلّم مناسبة لكِ.

ربط الاختبار بجدول Google Sheets — خطوات التنفيذ (مرة واحدة فقط)
  1. أنشئي جدولاً جديداً في Google Sheets وسمّيه مثلاً «نتائج التشخيص – التاسع».
  2. من القائمة: الإضافات ← Apps Script (Extensions ← Apps Script).
  3. احذفي الكود الموجود، والصقي الكود أدناه ثم احفظي.
  4. اضغطي Deploy ← New deployment ← Web app، واضبطي:
    «Execute as» = Me ، و«Who has access» = Anyone، ثم Deploy ووافقي على الأذونات.
  5. انسخي الرابط المنتهي بـ /exec.
  6. افتحي ملف الاختبار بأي محرر نصوص، وابحثي عن السطر:
    const SHEET_URL = ""; وضعي الرابط بين علامتي التنصيص، ثم احفظي الملف وارفعيه.

بعدها تصل نتيجة كل طالبة إلى الجدول تلقائياً لحظة ضغطها زر التصحيح، ويبقى الحفظ المحلي يعمل كنسخة احتياطية.

function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName("النتائج") || ss.insertSheet("النتائج");
  if (sh.getLastRow() === 0) {
    sh.appendRow(["التاريخ والوقت","اسم الطالبة","الشعبة","العلامة من 48","النسبة %","مستوى الأداء",
      "علوم الحياة /10","الكيمياء /10","الفيزياء /10","علوم الأرض /10","قراءة الرسوم /8",
      "زمن الإنجاز (دقيقة)","محاور تحتاج معالجة","الدروس التي ظهر فيها الضعف"]);
  }
  var d = JSON.parse(e.postData.contents);
  sh.appendRow([new Date(), d.name, d.cls, d.raw, d.pct, d.level,
    d.bio, d.chem, d.phys, d.earth, d.vis, d.mins, d.weakBranches, d.weakTopics]);
  return ContentService.createTextOutput(JSON.stringify({ok:true}))
    .setMimeType(ContentService.MimeType.JSON);
}
